A Comparative Study of the Travelling Salesperson Problem Using Branch and Bound and Nearest Neighbor Algorithms

Solving the asymmetric delivery routing challenge by evaluating the exact Branch and Bound algorithm with matrix-reduction lower bounding against the fast greedy Nearest Neighbor heuristic. Integrated with OpenStreetMap Nominatim for geocoding, OSRM for real road distances, and SQLite for persistent audit records.

ALGORITHMS IMPLEMENTATION

Comparing exact combinatorial optimization against greedy approximations for the Travelling Salesperson Problem.

Exact Algorithm

Branch and Bound (LCBB)

Explores the state space tree using Least-Cost Branch and Bound. At each node, computes a rigorous lower bound via row and column cost matrix reduction. Prunes unpromising subtrees whenever the lower bound meets or exceeds the best-known tour cost.

Optimality Guaranteed Exact Optimum
Worst-Case Time O(N! · N²)
Average Time O(N² · 2ⁿ) with reduction
Data Structure Min-Heap Priority Queue
Heuristic Algorithm

Nearest Neighbor

A greedy polynomial-time heuristic. Starting at the designated warehouse, it iteratively visits the nearest reachable unvisited destination until all destinations are satisfied, and finally closes the circuit by returning to the origin.

Optimality Suboptimal / Heuristic
Time Complexity O(N²)
Space Complexity O(N) Visited Array
Trade-off Instant speed vs Suboptimality
Criterion Branch and Bound (LCBB) Nearest Neighbor
Approach Exact state-space search with matrix reduction pruning Greedy local selection heuristic

Method: Branch and Bound (LCBB with Matrix Reduction Lower Bounds)
Mathews (AP25110070852) & Shubham (AP25110070745)

Explores the state space tree using Least-Cost Branch and Bound (LCBB). At each candidate node, computes a rigorous lower bound by reducing the row and column costs. Any branch with Lower Bound ≥ current best tour is strictly pruned, mathematically guaranteeing the global minimum delivery cost.

1. Matrix Reduction Bound

Subtracts row minima and col minima to obtain initial lower bound LB₀.

2. Priority Queue Search

Always expands the lowest lower-bound node from the Min-Heap priority queue.

3. Subtree Pruning

Discards suboptimal routes immediately when their lower bound exceeds best known cost.

4. Mathematical Optimality

Guaranteed lowest total fuel and vehicle expense for the entire delivery cycle.
